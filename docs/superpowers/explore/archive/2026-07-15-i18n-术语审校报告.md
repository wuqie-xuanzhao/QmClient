# i18n 术语与维护源审校报告

## 审校立场
- **英文 source 也可能错**，不能只机翻中文。
- 维护源：`translations/i18n/*.toml`；术语表：`prompt_assets/terminology.toml`；机翻提示：`system_prompt.md`。
- 玩家可见短标签优先社区习惯，不跟错误词根死磕。

## 已确认并修正

| 英文（修正后） | 简中 | 问题 |
|----------------|------|------|
| Dummy copy / Dummy copy: %s | 分身同步 | 旧 key 用 Dummy sync；译成「分身同步动作」 |
| Show dummy copy status | 显示分身同步状态 | 旧 Show dummy sync status |
| Show in-game HUD (dummy copy state) | 显示游戏内 HUD（分身同步状态） | 旧 clone sync state |
| Hook collisions | 钩子辅助线 | 旧「钩索碰撞」字面 |
| Show Hook Collision / Toggles hook collision | 显示/切换钩子辅助线 | 残留「钩子碰撞」 |
| Freeze … border color | 冻结…边框颜色 | 中文 UI 残留英文 Freeze |
| Air jump / unlimited air jumps | 空中跳 / 无限空跳 | 统一术语 |

语义依据：`cl_dummy_copy_moves` + bind `Dummy copy`；HUD 状态行应与 copy 一致，而非另造 Sync。

## 扫描方法
- 对 `simplified_chinese.txt` 做启发式：`同步动作`、Dummy 未本地化、钩索碰撞、英文直出、机翻「进行…」等。
- 高优先级人工确认后改 TOML / 源码 Localize 字面量，再 `extract → generate → validate`。

## 残留观察（未本轮全改）
- 大量帮助文本含配置名/命令（`cl_*`、`/rescue`）属**应保留英文 token**，不是漏译。
- `Practice mode` 在长句中有时译「练习模式」变体，术语 enforce 改为 `prompt_only` 避免误杀。
- 其它语言（日/韩/欧）仍可能保留 Dummy/sync 字面，后续可按术语表批量校对。

## 提示词与术语表
- `system_prompt.md`：补充英文 source 审校、Dummy copy / 钩子辅助线 / 冻结等硬规则，禁止机翻味。
- `terminology.toml`：扩充 Dummy/Hook/Air jump/Freeze 等；文件头注明 enforce 语义。

## Release Note（并行评价）

- **问题（已收）**：`refactor(ui)` 海量实现重构进草稿，玩家无感；默认已排除 refactor。
- **Nightly**：应提示「由 commit 自动汇总 + 预构建」；对比最近正式版 tag。
