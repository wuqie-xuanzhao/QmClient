# 通知栏 i18n 术语扫描报告

## 范围与方法

- **代码真相**：`hud_notification_catalog.cpp`（canonical / dynamic）、`hud_notification_static_*.h`（服务器原文 → Localize key）、`hud_notification_rules.cpp`（`Localize` / `str_format(Localize(...))` 动态模板）、`hud_notifications.cpp`（solo 直出）。
- **维护源**：`qmclient_scripts/languages_qmclient/translations/i18n/*.toml`（通知文案主要在 `qmclient.toml`，少量动态模板在 `misc.toml`）。
- **产物交叉**：`data/languages/simplified_chinese.txt`（只读校验，禁止手改）。
- **枚举结果**：可展示英文 source key **约 224 条**（catalog 10 + static Localize 目标 ~160 + rules 动态模板 ~50+；已去重；不含纯中文服务器别名匹配串）。
- **覆盖**：224/224 在 TOML 有 `simplified_chinese`（无 missing 回退 EN）。

术语对照：`prompt_assets/terminology.toml` + 既有报告 `2026-07-15-i18n-术语审校报告.md`（Dummy copy / 钩子辅助线 / 空中跳 等）。本模块**无 Dummy/Freeze/钩子辅助线** UI 文案；Hook 相关为玩法状态（互钩 / 无限钩 / 按住钩子）。

## 优先级说明

| 级           | 含义                                                  |

| **P0** | 明显错误 / 英文残留导致中文 UI 不可读 / 拼接语法崩坏  |

## 架构备注（非本轮必改）

1. **双重路径**：上游 EN 经 `Localize(canonical)`；服务器已中文时靠 static alias / 规则里中文前缀匹配，再落到同一 EN key 的 Localize。
2. **static 表中文别名**（如「你现在会收到私聊消息」）是**匹配输入**，展示仍走 EN key 的翻译；故 TOML 必须与 alias 语义对齐（本轮已对齐 whispers / rescue / timeout）。
3. **动态模板** `killed themselves` / `died` / `enable` / `disable` 是短 token，改 SC 时必须与父模板一起审，避免「自杀 了」类拼接事故。
4. **fallback** `Queue(..., Localize(pMessage))`：未识别服务器句会整句 Localize；未入库则原样英文。

## 未改（故意 / 低置信）

- `solo` / `super` / `tee` / 命令 token（`/lock` `/swap` `/kill` `/practice` 等）保留。
- 「被处死」社区用语，不强制改「被杀」。
- 其它语种（日韩欧）未扫。
- 未跑 `extract_strings`（纯译文修改）。
