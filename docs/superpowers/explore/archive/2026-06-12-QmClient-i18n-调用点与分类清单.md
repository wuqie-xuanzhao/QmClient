## 当前结论

1. 第一阶段可以先做 `console / hud / menus_ingame / menus_settings_controls / touch_controls` 这类低风险、纯 UI 的英文 key 迁移。
2. `chat.cpp`、`menus_browser.cpp`、`race_parse.cpp` 这类文件需要先人工裁决，不适合直接批量推进。
3. overlay 删除不能和第一批文案迁移绑死，因为它还被运行时主链、脚本链和测试链同时依赖。
4. 私有简中旁路必须单独挂牌，否则后面即使去掉中文 key，也仍会保留多条 i18n 查询路径。
5. `batch C` 已先收一批明确 UI 项：`chat.cpp` 的翻译设置弹窗标签、`menus_demo.cpp` 的截图预览/目录 tooltip、`menus_browser.cpp` 收藏列表表头与空备注占位；命令预览与分类语义映射仍保留待裁决。
