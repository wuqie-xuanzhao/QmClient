# i18n 维护源机翻味扫描与修复

## 范围

- 真相源：`translations/i18n/*.toml`（9 模块，约 4500+ message）
- 语言：以 **simplified_chinese** 为主，同步修正 **traditional_chinese**
- 产物：`generate_all.py` → `data/languages/*.txt`（禁止手改）

## 方法

1. 启发式扫描 SC：机翻模板（点击以 / 将会被 / 进行中 / 突出显示 / 实体物 / 以秒为单位…）
2. 术语表 `prompt_assets/terminology.toml` 对照（Dummy / Hook / Air jump / Grenade…）
3. 高置信逐条改写，不批量 LLM 回填
4. `generate_all` + `validate --incremental`

## 已修（摘要）

| 类型 | 例 |
|------|----|
| 通知/提及 | 「突出显示你时让客户通知」→「有人提及你时通知」 |
| 队伍进度 | 「…进行中」→「正在保存/尚未完成/比赛中…」 |
| 存活冻结 | `live freeze` 残留 →「存活冻结」 |
| Solo | `solo 状态` →「单人区域」 |
| 钩线 | 「实体物」→「可钩物体」；辅助线用「钩子辅助线」 |
| Dummy HUD | 「分身操作」→「分身控制」 |
| 武器 | 「枪火/榴弹炮」→「开火/榴弹」 |
| 空中跳 | 「无限空跳」→「无限空中跳」（术语表同步） |
| 配置单位 | 「以秒为单位」→「（秒）」 |
| 其它 | ranbow typo、serverinfo 直出、开发以及赞助者、同上上 等 |

约 **57** 处维护源改写（含系统化「秒」单位统一）。

## 有意保留

- **钩索**作为钩子动作/武器译名（社区习惯）；与「钩子辅助线」区分
- 命令 `/load`、配置 `cl_*` 等 token 保持英文
- length / `% to` 类 validate **WARN** 不阻断

## 验证

- `generate_all.py`：12 语覆盖 active keys
- `validate --incremental`：blocking quality errors = 0（修术语后）

## 残留（可选下一轮）

- loading 等模块仍有缺译/偏直译长句（本轮聚焦机翻味）
- 其它语种（日韩欧）未做对等润色
- 更细的「当…时」状语可继续人工抽检
