## Task 2: `stableId→连续 index` O(1) 注册表

**Files:** 同 Task 1（`QmCardOrderModel.h/.cpp` + test）

**背景：** 栖梦靠 `EQmModuleId` 连续枚举白嫖 O(1) state 查找（`GetQmModuleStateIndexById :1594`）。全局卡用字符串 stableId 没有连续枚举，若线性查找会让位退化 O(N²)（设计文档 §8.2，性能地基）。

**Step 1: 写失败测试**

```cpp
// 意图：让位 lerp 每帧每卡查 state index，必须 O(1)——否则 69 卡拖拽掉帧
TEST(QmCardOrderModel, StateIndexIsOLookupByStableId)
{
	qm_card_order::CModel M;
	M.SetEntries({{"qm:a", "t", 1, 0}, {"qm:b", "t", 1, 1}, {"qm:c", "t", 1, 2}});
	M.BuildStateIndex();  // 构建 stableId→连续 index
	// 已知 id O(1) 命中
	EXPECT_EQ(M.StateIndexForStableId("qm:b"), 1);
	// 未知 id 返回 -1（容错，不崩溃）
	EXPECT_EQ(M.StateIndexForStableId("qm:unknown"), -1);
}
```

**Step 2: 跑测试看红**（`M.BuildStateIndex` / `StateIndexForStableId` 不存在 → 编译失败）

**Step 3: 最小实现**
- `CModel` 加 `std::unordered_map<std::string, int> m_StableIdToState;`
- `void BuildStateIndex();`——遍历 `m_vEntries`，`m_StableIdToState[m_pStableId] = 连续 index`
- `int StateIndexForStableId(const char *pStableId) const;`——map 查找，未命中返回 -1
- `SetEntries` 后自动调 `BuildStateIndex`（或要求调用方显式调——测试驱动选自动）

**Step 4: 跑测试看绿** → 全 PASS

**Step 5: gate + commit**
```bash
git commit -m "feat(qmclient): CModel 加 stableId→index O(1) 注册表（性能地基）"
```

	EXPECT_EQ(std::string(qm_card_registry::MigrateLegacyKey("qiafen")), "qm:qiafen");
	EXPECT_EQ(qm_card_registry::MigrateLegacyKey("keyword_reply"), nullptr);

TEST(QmCardRegistry, AllQimengLegacyKeysMigratable)
{
	// 栖梦 38 个 m_pKey 必须全部可映射（迁移兜底全覆盖）

	{
		std::string Id = E.m_pStableId;
		if(Id.rfind("qm:", 0) == 0)
		{
			std::string Legacy = Id.substr(3);
			EXPECT_NE(qm_card_registry::MigrateLegacyKey(Legacy.c_str()), nullptr)
