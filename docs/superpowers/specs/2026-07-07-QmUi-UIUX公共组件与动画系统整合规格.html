1 · 成功口径

本轮 UI/UX 收口的成功标准不是“新增一批看起来相似的控件”，而是设置页里的卡片、输入框、滚动条、dropdown 和动画状态都只剩一套可复用路径。

  • QmClient/栖梦页面当前卡片样式是设置页卡片视觉权威。
  • Settings、QmClient、TClient、Search 等页面复用同一组 card shell/layout、scroll preset、input shell、dropdown policy。
  • 页面业务代码只负责内容和配置项，不再手写卡片 chrome、padding、滚动条宽度、popup 裁剪或输入框外壳。
  • 动画系统基于现有 QmUi runtime 增量接入，不引入外部 UI 或动画库。
  • 结构测试、默认 gate 和人工视觉/行为检查共同达成后，才能把目标标为完成。
不能接受的完成口径：只靠源码字符串测试通过、局部页面看起来接近、或保留旧 helper 给部分页面继续调用，都不能算完成。

1.1 · 目标模式

目标模式是“单一设置页 UI 组件体系”，不是“每页复制一份相似样式”。任何新迁移页面必须能回答它消费的是哪一个公共 primitive，以及旧路径是否已经不可再被生产页面调用。

对象目标模式完成判定
卡片 QmClient 页面卡片参数是视觉权威；所有设置页通过 QmSettingsCardStyle、QmSettingsCardLayout、RenderQmSettingsCardShell 获得外壳和内容区。 Graphics、Sound、DDNet、Appearance、QmClient、Search、TClient 的卡片入口不再手写外壳、padding、强制单列或旧 drag wrapper。
全局卡片 Model 卡片是 first-class 全局组件；stableId 不编码 tab，当前位置由 (tab, column, order) 决定。 搜索、拖拽、顺序持久化、reset/defaults、新增卡补位都从同一注册表和同一 Model 派生。
Search 页面 Search - 搜索 是独立设置页，搜索所有可见全局卡片；QmClient 页面不再保留局部搜索。 搜索结果包含 qm:、tclient:、deck: 等命名空间，结果卡片样式与 QmClient 卡片一致。
滚动条 页面竖向滚动条、dropdown 内部滚动条和横向滚动条使用共享 large/medium/small preset。 业务页面不再手写与 QmClient 冲突的 thickness/margin；真实滚轮速度接近 DDNet 原本手感。
输入框 搜索框、普通文本框、清除文本框共用 visual shell 和基础 editbox 行为。 无双层深色 plate、无左右短一截、无 placeholder 重影；点击光标、拖选、选中替换和失焦保存均通过真实操作验收。
Dropdown 长列表和短选项共享定位、裁剪、hit-test、wheel policy；只在滚动归属和高度约束上分策略。 滚轮不关闭 popup；短选项保持页面滚动路径，长列表内部滚动；父容器 clip 后不可见区域不能绘制或响应鼠标。
动画 已有 QmUi runtime 是唯一动画基础；页面入场、hover、press、拖拽释放和滚动缓动使用命名 token。 每页节奏一致，首次入场不漂移，拖拽让位/释放动画可见且不抖，Motion Level 0/1/2 行为明确。
当前计划状态：docs/superpowers/plans/2026-07-07-全局卡片与公共控件收口计划.md 不能标记为全部完成。它已有部分红绿灯、结构测试、run_cxx_tests 和 default gate 记录，但仍缺跨页面人工视觉验收、dropdown clip/hit-test 实机验证、输入框鼠标行为验收和最终代码审查。

2 · 系统层级

层级职责当前落点约束
Theme / Token 颜色、圆角、间距、字体、motion token。 src/game/client/QmUi/UiTokens.h、既有菜单色彩管线。 主题运行时改造必须先核对当前配置链，不把旧 QmThemeRuntime 方案直接照搬。

Settings Integration Settings/QmClient/TClient/Search 页面渲染、全局卡片注册、拖拽、持久化。 menus_settings.cpp、menus_qmclient.cpp、menus_tclient.cpp。 页面只组合公共组件，不定义另一套视觉和拖拽模型。

3 · 公共组件契约

3.1 卡片

设置页卡片唯一视觉参数链路如下：

ui_widget::QmClientCardProps()
  -> CMenus::QmSettingsCardStyle(float UiScale)
  -> CMenus::QmSettingsCardLayout(...)
  -> CMenus::RenderQmSettingsCardShell(...)
  • QmSettingsCardLayout(...) 只负责几何：外框、内容区、标题区、拖拽把手区。
  • RenderQmSettingsCardShell(...) 只负责公共外壳：背景、边框、highlight、标题预留、拖拽把手。
  • 业务页面只能在 m_ContentRect 内绘制内容，不允许再 RenderQmSettingsGlassCard + Margin 手写内容区。
  • 双列布局、列间距、卡片间距和 shared deck 的 card width 由公共 deck/card layout 决定。
  • 拖拽代理、drop indicator、让位动画、释放动画和顺序持久化使用同一套 card item 注册信息。

3.2 输入框

搜索框、纯文本输入框、带清除按钮输入框共享同一个 visual shell 和基础 editbox 行为。

组件目标验收点
TextFieldEx普通文本输入。点击定位光标、拖选、双击全选、选中替换、失焦保留值。
ClearableTextFieldEx文本输入 + 清除按钮。清除后焦点和 placeholder 状态正确，不出现残影。
SearchFieldEx搜索输入 + 搜索语义。不重复绘制外层 plate，placeholder 不和真实文本重影。
  • 输入框内部不能出现双层深色 plate、左右短一截或 placeholder 文本重影。
  • 普通 DoEditBox() 的基础编辑能力属于公共能力，QmUi 封装不得只覆盖搜索框特例。
  • 如果未来加入输入框组合控件，输入框仍接受数字和无限符号，滑块只负责有限范围或最右无限状态。

3.3 滚动条与滚动容器

  • 设置页竖向滚动条宽度、边距、轨道和 thumb 基础参数以 QmClient 页面为准。
  • 公共滚动条提供 large/medium/small preset；业务页面按语义选择 preset，只允许覆盖滚动单位等行为参数。
  • 横向和竖向滚动都通过公共参数结构表达。
  • 滚轮速度必须对齐 DDNet 原有手感和 g_Config.m_UiSmoothScrollTime，不得凭主观 review 随意调慢或调快。
  • 滚动容器可使用 CQmScrollContainer / QmScrollContainerStyleForSize，但真实手感以客户端验证为准。

3.4 Dropdown

Dropdown 明确分为长列表型和短选项型，但两者共享状态、定位、裁剪和滚轮策略。

类型例子滚轮策略高度策略
长列表型 Tee 国旗、设备列表、字体列表。 popup 内部优先滚动，显示内部滚动条。 使用最大可见项数或可见区域约束。
短选项型 Graphics 窗口模式、二三项枚举。 默认页面滚动路径继续工作，popup 保持打开。 默认无内部滚动条；超过高度上限或被裁剪时切换内部滚动。
  • Dropdown 打开期间，滚轮不能关闭 popup。关闭只允许由选择、Esc、外部点击或既有明确关闭路径触发。
  • Popup 位置以触发控件当前 rect 为锚点，滚动后重新跟随控件真实位置。
  • Popup 的绘制、hit-test、wheel hot region 必须尊重父 clip/遮挡关系。
  • 被父容器裁掉的 popup 区域不能覆盖上方内容，也不能响应鼠标。

3.5 其他组件

  • Button、segmented control、toggle、slider、color picker、modal、toast 和 icon library 仍属于公共组件目标，但本轮优先级低于卡片、输入框、滚动条和 dropdown。
  • 旧 UI/UX 文档中的 Phosphor/MSDF 图标、SDF 圆角、SDF 文本属于后续画质路线，不进入当前全局卡片收口的完成条件。
  • 组件新增前必须先检查 QmUi 现有组件，不得为单页需求复制一个外观相近的新控件。

4 · 动画系统契约

QmUi 动画系统当前不需要外部库。规格目标是把已有 runtime 能力稳定接入公共组件，并用视觉验收校准手感。

能力当前状态目标契约
Motion Level已存在所有新增动画必须支持 0=关闭、1=减少、2=完整。
Spring / Tween / interrupt policy已存在hover、press、drag release、presence 使用命名 token，不在页面散写参数。
Scroll physics / ScrollContainer已实现并接入部分设置页手感靠真实客户端校准，速度优先接近 DDNet 原本滚动。
Layout transition / FLIP部分实现shared deck 已接入卡片拖拽让位和释放动画；TClient 主设置页 wrapper 仍需把业务内容渲染迁到 animated display rect，不能只注册 shared card item。
AnimatePresence已实现用于 toast、modal、候选框、页面局部出现消失；避免节点直接消失。
Runtime target cache 实例化已实现缓存生命周期跟随 runtime，不回退到全局 static。
OKLAB color interpolation已实现作为颜色动画能力保留，具体 UI 使用需逐项验收。
AwaitTracks / custom easing已实现复杂组合动画可等待多轨道完成；自定义 easing 生命周期必须明确。
真实视觉手感未完全验收卡片拖拽释放、滚动速度、页面入场动画必须人工看客户端。
动画准则：首次进场动画要短而克制，不能像缓慢漂移；页面之间不能各自有不同入场节奏；滚动速度和缓动必须接近 DDNet 原本手感，只有明确验证更好时才调整。

5 · 页面与全局卡片集成

5.1 页面目标

页面目标不得保留
QmClient 作为当前卡片样式基准，但自身也走公共 card shell、scroll container 和公共输入框。 本地搜索栏、本地 card chrome、本地滚动参数。
Search Search - 搜索 是独立设置页，展示所有可搜索全局卡片。 只搜 QmClient 本地卡片；灰蒙蒙且与 QmClient 卡片不一致的结果卡片。
TClient 主设置页、ChatBinds、BindWheel、StatusBar 等迁移到公共 shell/deck。 TClientCacheSectionBoxRect、InsetTClientCacheSectionContent、DrawTClientCacheSectionBox 等旧路径；主页面不得保留内容不随 layout transition 运动的本地 wrapper。
Settings 常规页 Graphics、Sound、DDNet、Appearance 等逐步清空手写卡片和滚动条分叉。 私有 card width、强制单列、私有 scrollbar thickness/margin。

5.2 全局卡片 Model

  • 全局卡片注册、搜索、拖拽顺序和持久化继续对齐 2026-06-29-全局卡片架构-统一拖拽与持久化.html。
  • 跨页面组件编辑器、stableId、reset/defaults 行为继续对齐 2026-06-29-全局卡片-组件编辑器与stableId设计.md。
  • 本规格不重复定义 B1/B2 Model 细节，只规定 UI primitive 和页面集成必须消费同一 Model。

7 · 验收证据

7.1 自动验证

文档或实现变更完成后，按范围选择验证。当前公共 UI 收口实现提交前至少需要 default gate。

python qmclient_scripts/gate/check_docs.py
git diff --check
cmd /c qmclient_scripts\cmake-windows.cmd --build cmake-build-release --target run_cxx_tests -j 14
python qmclient_scripts/gate/check_gate.py --mode default
  • 只改 specs/plans 文档时，至少跑 check_docs.py 和 git diff --check。
  • 改 C++ UI 行为时，必须跑相关 focused tests，再跑 run_cxx_tests。
  • 提交或交付实现前优先跑 check_gate.py --mode default。

7.2 人工视觉与行为检查

当前人工审验入口是 cmake-build-release\DDNet.exe。如该进程正在运行，后续重建前需要先关闭同一路径客户端；不要用其他构建目录的产物替代本轮验收。

场景必须检查
QmClient 页面双列布局、卡片宽度、卡片间距、滚动条宽度、拖拽让位动画。
Search 页面结果卡片样式、全局搜索范围、双列布局、滚动手感。
Graphics 页面窗口模式 dropdown、输入框样式、短列表 popup 裁剪和滚轮路径；滚动整页时短 popup 右侧不得闪烁内部滚动条。
Tee 国旗 dropdown长列表内部滚动条、鼠标滚轮归属、父容器裁剪。
TClient 页面卡片样式与 QmClient 完全一致，双列占位合理，上下间距正确，拖拽代理/drop indicator/释放动画不分叉。
顶部子 tab子 tab 栏使用当前内容区全宽，不被单列卡片宽度、二次 inset 或旧 wrapper 缩窄。
输入框点击光标、拖选、双击全选、选中替换、点击外部保存、placeholder / 提示文本不重影。
滑动条+输入框输入框使用公共 QmUi field，支持数字和 ∞，focus ring 与普通输入框一致，数字和光标位置对齐。
动画与滚动首次入场不漂移、每页节奏一致、滚动速度接近 DDNet 原本手感；必须记录与官方 DDNet 参数的对比结论。
