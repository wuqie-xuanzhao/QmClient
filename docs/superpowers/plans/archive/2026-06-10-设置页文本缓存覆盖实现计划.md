# 设置页文本缓存覆盖 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-06-10-设置页性能优化总纲.md` 的 Phase 1 / P0-A，把设置页静态文本从每帧 immediate label 绘制逐步迁移到现有 `SettingsTextElement()` / `DoSettingsLabelStreamed()` 缓存路径，并让 `text_new` / `text_reused` telemetry 真正可验收。

**Architecture:** 不新增文本缓存系统，只扩大现有 `CUIElement::SUIElementRect` 文本容器缓存覆盖。先补 active text perf stats scope，再分批迁移 General/Language、TClient、QmClient 的静态标题和说明文本；动态值、输入框内容、每帧变化状态和 hover-only tip 不进入第一批。

**Tech Stack:** C++, DDNet CUI, `CUIElement`, GoogleTest source-contract tests, CMake Windows gate, existing `perf/section` telemetry.

---

## Scope

本计划只覆盖设置页静态文本缓存。它不做：

- FBO / render target / recorded target / blit 缓存。
- Section 测量延迟化或视口外 widget skip。
- 皮肤列表虚拟化。
- QmUI runtime 优化。
- Server Browser / Demo Browser / 全局 scheduler。

第一批允许迁移的文本类型：

- section 标题，例如 `Visual: Font & Cursor`、`Demo`、`Gameplay`、`Background`。
- 稳定字段 label，例如 `Name`、`Clan`、`Custom Font:`、`Map`。
- 稳定说明文字，例如 QmClient overview card 的固定文案。

第一批不迁移：

- 输入框内容、搜索框内容、玩家名、皮肤名、配置值。
- hover-only tip，除非本任务同时为它建立稳定 key 且证明颜色/尺寸变化不会导致每帧重建。
- 带 unread/new feature 动态标记的标题。
- 语音/监控状态等实时状态文本。

- [ ] **Step 2: Add the scoped stats helper**

In `CMenus` private section near `SSettingsTextPerfStats`, add:

```cpp
class CScopedSettingsTextPerfStats
{
	CMenus *m_pMenus = nullptr;
	SSettingsTextPerfStats *m_pPrevious = nullptr;
	SSettingsTextPerfStats m_Stats;

public:
	explicit CScopedSettingsTextPerfStats(CMenus *pMenus) :
		m_pMenus(pMenus),
		m_pPrevious(pMenus->m_pActiveSettingsTextPerfStats)
	{
		m_pMenus->m_pActiveSettingsTextPerfStats = &m_Stats;
	}

	~CScopedSettingsTextPerfStats()
	{
		m_pMenus->m_pActiveSettingsTextPerfStats = m_pPrevious;
	}

	const SSettingsTextPerfStats &Stats() const { return m_Stats; }
};
```

Keep the helper private to `CMenus`; do not expose it outside settings rendering.
