# 设置页 Section 测量延迟化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-06-10-设置页性能优化总纲.md` 的 Phase 1 / P0-B1，让设置页 section loader 只在已有稳定 cached height 且 section 远离视口时延迟本帧测量，减少多 section 页重复测量成本。

**Architecture:** 不改页面布局结构，不引入 FBO、render target 或页面录制缓存。先在 `SSettingsSection` 增加 cached-height validity 合同，再给 `CSectionLoader` 增加可开关的 deferred far measurement 模式；首批只在 TClient 的 section loader 上启用，用已有 section loader 单测补齐 RED/GREEN 合同。

**Tech Stack:** C++, `CSectionLoader`, DDNet CUI, GoogleTest, CMake Windows gate, existing `perf/section_loader` telemetry.

---

## Scope

本计划只覆盖 **Phase 1 / P0-B1：Section 测量延迟化**。

本计划做：

- 为 `SSettingsSection` 增加“cached height 是否可信”的显式状态。
- 为 `CSectionLoader` 增加一个关闭默认、页面可选择启用的 deferred far measurement 模式。
- 仅当 section 远离视口、已有 cached height、且未 dirty 时，跳过本帧 `MeasureFn` 并用 cached height 推进列位置。
- 在 TClient settings 的 `s_VisualFontLoader` / `s_RightSectionLoader` 上启用该能力。
- 补充 `section_loader_test.cpp` 的 RED/GREEN 测试。

本计划不做：

- P0-B2：视口外 section 跳过 widget 调用。
- P1-F：布局脏检测 + section 高度持久缓存。
- QmClient 模块系统重写。
- Tee 皮肤列表虚拟化。
- FBO / render target / recorded target / blit 缓存。

Add two tests to `src/test/section_loader_test.cpp`.

First test: far section must not skip first measurement when height is unknown.

```cpp
TEST(SectionLoader, DeferredFarMeasurementRequiresKnownHeight)
{
	CSectionLoader Loader;
	Loader.SetProgressiveEnabled(false);
	Loader.SetDeferredFarMeasurementEnabled(true);
	int FarMeasureCount = 0;

	SSettingsSection Top = MakeTestSection("Tall Top", 900.0f);
	SSettingsSection Far = MakeTestSection("Far Section", 50.0f);
	Far.m_MeasureFn = [&FarMeasureCount](CUIRect &Rect) -> float {
		++FarMeasureCount;
		return ConsumeHeight(Rect, 50.0f);
	};

	Loader.Register({Top, Far});
	Loader.Begin(CUIRect{0, 0, 400, 240}, 100.0f);

	EXPECT_FALSE(Loader.Process());
	EXPECT_EQ(FarMeasureCount, 1);
	EXPECT_FLOAT_EQ(Loader.GetRunningColumn().y, 950.0f);
}
```

Second test: once cached height is known and section is far + clean, a later frame can skip remeasure.

```cpp
TEST(SectionLoader, DeferredFarMeasurementUsesCleanCachedHeight)
{
	CSectionLoader Loader;
	Loader.SetProgressiveEnabled(false);
	Loader.SetDeferredFarMeasurementEnabled(true);
	int FarMeasureCount = 0;
	int FarFullRenderCount = 0;

	auto MakeSections = [&]() {
		SSettingsSection Top = MakeTestSection("Tall Top", 900.0f);
		SSettingsSection Far = MakeTestSection("Far Section", 50.0f);
		Far.m_MeasureFn = [&FarMeasureCount](CUIRect &Rect) -> float {
			++FarMeasureCount;
			return ConsumeHeight(Rect, 50.0f);
		};
		Far.m_RenderFullFn = [&FarFullRenderCount](CUIRect &Rect) -> float {
			++FarFullRenderCount;
			return ConsumeHeight(Rect, 50.0f);
		};
		return std::vector<SSettingsSection>{Top, Far};
	};

	Loader.Register(MakeSections());
	Loader.Begin(CUIRect{0, 0, 400, 240}, 100.0f);
	EXPECT_FALSE(Loader.Process());
	EXPECT_EQ(FarMeasureCount, 1);
	EXPECT_EQ(FarFullRenderCount, 0);

	Loader.Register(MakeSections());
	Loader.Begin(CUIRect{0, 0, 400, 240}, 100.0f);
	EXPECT_FALSE(Loader.Process());
	EXPECT_EQ(FarMeasureCount, 1);
	EXPECT_EQ(FarFullRenderCount, 0);
	EXPECT_FLOAT_EQ(Loader.GetRunningColumn().y, 950.0f);
}
```

TEST(SectionLoader, DeferredFarMeasurementDoesNotSkipDirtyHeight)
{
	CSectionLoader Loader;
	Loader.SetProgressiveEnabled(false);
	Loader.SetDeferredFarMeasurementEnabled(true);
	int FarMeasureHeight = 50;
	int FarMeasureCount = 0;

	auto MakeSections = [&]() {

const CUIRect EstimatedSectionRect{m_MainView.x, m_RunningColumn.y, m_MainView.w, Section.m_CachedHeight};

	Section.m_HasCachedHeight &&
	!Section.m_Dirty &&
	ComputeViewportPriority(EstimatedSectionRect) > 1;

	++m_CurrentIndex;
	continue;
}
