# 设置页 P1/P2 性能优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-06-10-设置页性能优化总纲.md` 的 Phase 1 队列完成 P1/P2：皮肤列表虚拟化、布局脏检测、QmUI runtime telemetry、Section 内 quad 批处理、减少非交互 `DoButtonLogic`。

**Architecture:** 这不是 Phase 2 的 FBO/纹理缓存计划；所有工作都保持 CPU 侧源头降温和可观测性增强。P1 先把 Settings Tee 的列表行成本从 `O(items)` 降到 `O(visible rows + bookkeeping)`，再补齐 section dirty key 与 QmUI 归因；P2 只在 P1 完成并有新 telemetry 证明 draw/input 仍是热点后才启动，且不跨 clip/scissor/text ordering 边界。

**Tech Stack:** C++, DDNet CUI/CScrollRegion/CListBox, QmUI `CUiRuntimeV2`, GoogleTest, CMake Windows build, `qmclient_scripts/perf` TypeScript analyzer, existing `perf/*` telemetry.

---

## Spec Phase Mapping

本计划实现的是总纲 `8.2 Phase 1：源头降温` 中剩余的 P1/P2 优先级，不启动总纲 `8.3 Phase 2：缓存（源头降温完成后）`。

| Plan task | Spec row | Priority | Completion boundary |
|---|---|---:|---|
| Task 1-2 | 策略 C：皮肤列表虚拟化，只遍历可见行 | P1 | Tee skin list 总长度不变，只对可见/预取行执行 row widget、tee preview、按钮逻辑，并输出 `rows_*` telemetry |
| Task 3 | 策略 F：布局脏检测 + 缓存 section 高度 | P1 | `CSectionLoader` 的 cached height 失效键覆盖 viewport、UI scale、language/font/backend/window/config，日志能说明 dirty reason |
| Task 4 | QmUI runtime telemetry 分离与补全 | P1 | `perf/ui_runtime` 带 settings page/operation、nodes、anim tracks、layout/bridge 字段，TS report 能单独归因 |
| Task 5 | 策略 E：Section 内 Quad 批处理 | P2 | 仅在 P1 新 telemetry 证明 draw calls / quad 提交仍是热点后启动；只批处理同一 section 内可安全合并的 static quads，不改变文本/quad 顺序和 clip/scissor |
| Task 6 | 减少非交互元素的 `DoButtonLogic` | P2 | 仅在 P1 新 telemetry 证明 passive input 扫描仍显著后启动；只移除 tooltip-only/passive icon 等不需要 hot/active/click 的调用，交互控件保持原行为 |

## Non Goals

- 不引入 FBO、render target、recorded target、blit cache 或页面纹理缓存。
- 不优化 Server Browser、Demo Browser、Assets/Workshop 之外的非设置页路径。
- 不把 `g_Config.m_ClSkinsLoadedMax` 或全局加载上限作为主优化手段。
- 不改变 Tee skin list 的排序、过滤、选择、收藏、队列、滚动到选中项语义。
- 不把 QmUI 简化成 `DrawCard` overdraw 猜测；先补独立 runtime telemetry。

In `src/game/client/components/settings_resource_jobs.cpp`, add:

```cpp
SSettingsSkinListVisibleRange SettingsSkinListVisibleRangeForScroll(float ScrollY, float ViewHeight, float RowHeight, int ItemsPerRow, int TotalItems, int ExtraRows)
{
	SSettingsSkinListVisibleRange Range;
	Range.m_TotalItems = std::max(0, TotalItems);
	if(Range.m_TotalItems <= 0 || RowHeight <= 0.0f || ItemsPerRow <= 0 || ViewHeight <= 0.0f)
		return Range;

	Range.m_TotalRows = (Range.m_TotalItems + ItemsPerRow - 1) / ItemsPerRow;
	const int FirstRow = std::max(0, (int)std::floor(std::max(0.0f, ScrollY) / RowHeight) - std::max(0, ExtraRows));
	const int LastRowExclusive = std::min(
		Range.m_TotalRows,
		(int)std::ceil((std::max(0.0f, ScrollY) + ViewHeight) / RowHeight) + std::max(0, ExtraRows));

	Range.m_FirstVisibleRow = std::min(FirstRow, Range.m_TotalRows);
	Range.m_LastVisibleRow = LastRowExclusive > Range.m_FirstVisibleRow ? LastRowExclusive - 1 : Range.m_FirstVisibleRow - 1;
	Range.m_FirstItem = std::min(Range.m_FirstVisibleRow * ItemsPerRow, Range.m_TotalItems);
	Range.m_EndItem = std::min(LastRowExclusive * ItemsPerRow, Range.m_TotalItems);
	Range.m_VisibleRows = std::max(0, LastRowExclusive - Range.m_FirstVisibleRow);
	Range.m_RenderedItems = std::max(0, Range.m_EndItem - Range.m_FirstItem);
	Range.m_SkippedItems = std::max(0, Range.m_TotalItems - Range.m_RenderedItems);
	return Range;
}
```

```cpp
void CListBox::SkipItems(int Count)
{
	Count = std::max(0, Count);
	while(Count > 0 && m_ListBoxItemIndex < m_ListBoxNumItems)
	{
		if(m_ListBoxItemIndex % m_ListBoxItemsPerRow == 0)
		{
			m_ListBoxView.HSplitTop(m_ListBoxRowHeight, &m_RowView, &m_ListBoxView);
			m_ScrollRegion.AddRect(m_RowView);
		}

		const int ItemsLeftInRow = m_ListBoxItemsPerRow - (m_ListBoxItemIndex % m_ListBoxItemsPerRow);
		const int ItemsToSkip = std::min(Count, ItemsLeftInRow);
		for(int i = 0; i < ItemsToSkip; ++i)
		{
			CUIRect Skipped;
			m_RowView.VSplitLeft(m_RowView.w / (m_ListBoxItemsPerRow - m_ListBoxItemIndex % m_ListBoxItemsPerRow), &Skipped, &m_RowView);
			++m_ListBoxItemIndex;
		}
		Count -= ItemsToSkip;
	}
}
```

This intentionally registers skipped row rectangles with `CScrollRegion::AddRect()` so scrollbar height and total list length still come from `NumItems`.
