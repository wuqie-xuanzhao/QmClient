## Implementation Requirements

Every implementation slice must include:

- A `Spec Phase Mapping` section that states the exact spec phase and priority row it implements.
- A same-path UI bug audit before production edits, covering the affected pages, tabs, scroll paths, and input paths.
- A baseline section using the current post-FBO baseline or a newer settings-only fixed scenario run.
- Red/green tests for the specific behavior being changed.
- Verification commands:

```powershell
qmclient_scripts/cmake-windows.cmd --build cmake-build-release --target run_cxx_tests -j 14
python qmclient_scripts/gate/check_gate.py --mode quick
```

If `check_gate --mode quick` only fails on the already documented unrelated `ruff format` findings in `qmclient_scripts/languages_qmclient/extract_strings.py` and `qmclient_scripts/languages_qmclient/generate_all.py`, record that as a gap and do not modify those scripts inside a settings performance child plan.
