# 目标

随包字体以用户整理后的 `data/qmclient/fonts` 目录为准；自定义字体继续走 FreeType，MTSDF 暂只针对一套内置字体做验收。

# 随包基线

- CMake 递归收集 `data/qmclient/fonts`，包含子目录、TTC、可变字体和 Phosphor 全部样式，保留相对目录名。
- 当前随包字体体积约 945 MB，以用户已经整理后的实际目录为准；不再自动删减或排除字体。
- `NotoSansCJK-VF.ttf.ttc` 仍是中日韩覆盖和首个 MTSDF 验收字体；其他字体目前统一走 FreeType。

# MTSDF 验收范围

- 当前只生成 `Noto Sans CJK SC` 一套验证图集。
- 通过验收后再按同一生成链扩展 JP/KR/TC/HK 和其他内置字体。
- 任何自定义字体均不进入 MTSDF profile，统一使用 FreeType。
