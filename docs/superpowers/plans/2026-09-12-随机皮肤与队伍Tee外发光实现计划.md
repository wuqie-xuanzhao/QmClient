# 1. 背景与决策

两个 enhancement issue 一起实现：

- Issue #157「新增随机皮肤按钮」：在当前皮肤队列内随机选择皮肤。issue 标题要的是随机按钮，报告人想要"每次进图换随机皮肤"，作者评论想法是"从队列随机位置开始轮换"。经确认，采纳组合方案：**手动随机按钮 + 进图随机起点开关**。
- Issue #158「tee外发光」：按分组（DDNet race 队伍）颜色给 tee 外轮廓绘制外发光；team0（未组队）支持 tee 颜色/自选颜色/彩虹三种来源。

# 2. 技术选型

## 2.1 #157 随机皮肤

- 复用 `CSkins::ApplySkinQueueIndex`（自带越界保护与应用逻辑），新增 `CSkins::RandomSkinQueueIndex(Dummy)`：空队列返回 false，非空时 `ApplySkinQueueIndex(rand() % size, Dummy)`。
- 进图随机起点在 `CSkins::UpdateSkinQueue` 的在线首帧分支实现（按 dummy 分别取 `qm_skin_queue_random_join` / `qm_dummy_skin_queue_random_join`）：轮换（重新）启动时随机化索引并清空追赶计时，覆盖进图上线、**分身单独连接**、重新启用队列三种触发；demo 回放因不满足在线条件天然排除。随机化发生在 `SyncSkinQueueFromMapPlayers` 之后，与服务器轮换模式叠加时从同步后的队列随机取位。
- **间隔 0 = 只在随机起点事件换肤**（2026-09-12 评审后新增）：`qm_skin_queue_interval` 下限放宽到 0，0 表示不做时间轮换——配合随机起点即"每次进图随机换一次皮肤后保持不变"，完整覆盖 issue 报告人"随机而非随时间轮换"的诉求。
- 外发光入口在 **Tee 设置页**，不在外观页；外观页的 Tee 标签及卡片注册已回退。
- **Tee 页卡片体系**（2026-09-12 二次评审后重组）：`deck:tee-skin-list`（全宽，纯皮肤列表与搜索工具栏）、`deck:tee-skin-queue`（左半宽，皮肤队列：启用轮换/间隔/进图随机换肤/队列列表/预设）、`deck:tee-glow`（右半宽，队伍外发光）为独立卡片；预览与选项卡保持不变。队列随机起点开关更名为"进图随机换肤"（Random skin on map join），tooltip 说明起点机制与间隔 0 的组合语义。
- team0 彩虹模式的相位：在线用本地时钟；**demo 回放用 demo 时间轴**（`m_CurrentTick - m_FirstTick` 换算秒），暂停即冻结，同一回放发光颜色可复现。
- 控制台命令 `random_skin_queue` / `random_dummy_skin_queue` 供绑定快捷键。
- 队列面板 UI：列表头垃圾桶旁新增骰子按钮（`EQmIcon::DICE_FIVE`）；间隔行下方新增"进图随机起点"checkbox。
- 与服务器轮换模式（`qm_skin_queue_rotate_map`）叠加：`SyncSkinQueueFromMapPlayers` 以"当前皮肤条目"为锚保留位置，随机起点选中的条目即当前条目，位置保持。

## 2.2 #158 队伍外发光

选择 **outline 层多次放大绘制**方案（无 FBO、无 additive、无新 shader）：

- tee 白色描边是 skin 贴图一部分；`RenderTee` 已支持 `TEE_PREVIEW_LAYER_OUTLINE | TEE_CUSTOM_OUTLINE_COLOR` 单独画轮廓并染色。
- 现成同构先例是 warlist 外发光（players.cpp）：复制 `CTeeRenderInfo` → 只画 outline 层 → 3 次放大(1.13/1.08/1.035) × 递减 alpha(0.10/0.18/0.30) 叠加成光晕。本次把该绘制提取为共用 helper `RenderTeeGlow`，warlist 与队伍外发光共用。
- 颜色来源：team ≥ 1 用 `CGameClient::GetDDTeamColor(Team, 0.75f)`（黄金角 hue，与名牌/聊天/计分板同源）；team 0 按配置模式：0=不发光、1=tee 自身颜色（未自色皮肤回退白光）、2=自选颜色（`qm_team_tee_glow_color`）、3=彩虹（时间循环 + 按 ClientId 黄金角错开相位）；超级队不发光。
- 优先级：warlist 外发光优先，未命中 warlist 时回落到队伍外发光。
- FBO + 高斯模糊后处理方案（`ui.cpp` 有完整 RenderTarget 链路）留作后续增强，V1 不采用。

# 5. 已知边界

- CSkins 不可单实例化，随机应用/随机起点沿用该组件既有合同测试层级，未建运行时单测。
- `RenderPlayerGhost`（预测残影）暂不加队伍外发光；demo 播放与旁观路径走 `RenderPlayer` 自动生效。
- team0"tee自身颜色"模式同时覆盖 0.6（`m_ColorBody`）与 0.7（sixup 部件色）渲染路径，两者都未自定义时回退中性白光。
- **场景行为**（2026-09-12 评审确认）：demo 回放中队伍发光正常（队伍信息随回放消息重建），彩虹按 demo 时间轴可复现；随机起点/轮换在回放中不生效；rank1 影子（ClientId<0）不发光（回放主体非队伍成员）；快速练习为在线玩法，发光行为与正常游戏一致。
- **红蓝团战不适配**（决策）：团战图没有 DDNet race 队伍概念，不做红蓝发光特判、不改动团战强制红蓝皮肤逻辑，避免影响玩法表达。
- 未做真机视觉验收（渲染效果需进图观察）；后续可按需启动开发实例检查旁观场景与 Tee 页右栏外发光卡片布局。
