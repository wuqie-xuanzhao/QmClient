# DDNet 19.8-20.0 版本基线审计

日期：2026-09-08

## 审计范围

核对 DDNet 19.8、19.9 到 20.0 的官方版本边界与提交状态，逐项对照当前 QmClient 分支。每条提交分为：原样合入、本地适配、功能等价、明确未合入、版本或发布策略不适用。

## 当前基线结论

- 当前 `src/game/version.h`：`DDNET_VERSION_NUMBER 19090`、`GAME_RELEASE_VERSION_INTERNAL 19.9`。
- 当前 `QMCLIENT_VERSION`：`3.0.2`。
- 仓库存在官方 `20.0` tag，但 `20.0` 不是当前 `HEAD` 的祖先；不能把当前分支称为完整 DDNet 20.0 基线。
- DDNet 19.9 同步提交 `ed2e89fde`、`aec0a1370` 已在当前祖先链中。
- 19.8 的版本 bump 提交 `f9e69715f` 不在当前祖先链中；19.8 内容是否已被后续同步吸收，必须按文件和提交逐项确认，不能按版本号推断。

## 已确认的官方范围

`19.9-rc1..20.0` 共 808 个提交。现有两份同步台账已经覆盖其中一部分：新增提交台账 89 条，旧台账复核 235 条；但台账状态包含 `adapted-local`、`covered-equivalent`、`deferred-*` 等分类，不能直接等价为“20.0 已合入”。

已确认进入当前代码或有本地等价实现的重点范围包括：snapshot delta 容量与失败传播、vanilla 0.6 暂停快照、playermapping 与旧客户端限制、任意客户端重连、old laser/GameInfoEx、输入时序、低刷新率渲染调度、macOS/iOS 适配、EGL headless/map_render、teehistorian role names、编辑器 modifier 快捷键及构建链更新。

## 当前未决项

1. 逐项生成 `19.9-rc1..20.0` 官方提交清单，并与新增台账、旧台账和当前文件差异做交叉匹配。
2. 对 `covered-equivalent` 与 `adapted-local` 条目补充实际代码位置和行为证据，区分真正功能等价与仅有相似结构。
3. 对 `deferred-platform`、`deferred-policy`、`deferred-protocol-batch` 和版本号条目单独列出，不混入已合入统计。
4. 审计完成前不把版本号从 19.9 改为 20.0。
