# 设置页性能优化最终收口报告

## 背景

本轮以 `docs/superpowers/specs/2026-06-11-设置页性能优化总纲-重组版.html` 为准，旧 plan 中依赖可见阶段补文本或局部补 key 的做法视为过时。

修复前基线为 `qm_perf_2026-06-14_02-15-18`：`targetSettings.stableTextCoverage.acceptanceBlocked=true`，主要缺口为 `unplannedVisibleCount=180`、`keyMismatchCount=30`、`miss=240`、`prebuildRemainingBeforeTarget=16`、`hitRate/reuseRate=32.58%`。

## 本轮收口内容

- stable text scrollbar key 改为 registry 与 visible wrapper 共用同一 style helper，避免 `appearance-freeze-bars-alpha-inside-freeze` 这类 multiline scrollbar 因 max-width/style 推导不一致产生 `key_mismatch`。
- `settings_text_prebuild.remaining` 改为基于当前 cached prebuild plan 统计，不再在每次日志输出时重新渲染完整 settings plan。
- 资源页 workshop/local preview admission 增加 combined visible window 口径，report 可显示 `visible_first`、`visible_starts`、`prefetch_starts`、`background_starts`，用于判断首屏是否被非可见资源抢占。
- perf report/bundle summary 增加 `assetsPreviewAdmission`，stable text blocker 继续以 `targetSettings.stableTextCoverage` 为验收口径。
