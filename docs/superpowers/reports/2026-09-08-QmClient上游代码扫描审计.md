# QmClient 上游代码扫描审计

日期：2026-09-08

## 结论口径

本报告只把当前源码、构建文件、资源和调用链作为合并证据。提交 hash、同步台账、计划文档和历史报告只用于定位候选，不计入“已合并”结论。

扫描来源：官方 `ddnet-upstream/master`、官方 `20.0` 源码树、QmClient wxj 上游 `upstream/master`、当前 `dyl_dev` 工作树。远程引用已刷新。

## wxj 上游扫描

当前源码树包含 wxj `upstream/master` 的全部业务源码路径。缺失的 17 个路径均有代码层解释：

- 14 个 `src/engine/external/wavpack/*` 文件已由 `ddnet-libs` 子模块和 `FindWavpack.cmake` 外部依赖替代；当前 `sound.cpp` 仍直接调用 WavPack API。
- `src/engine/shared/http.cpp`、`http.h` 已拆分为当前的 curl/Emscripten HTTP 实现与接口文件。
- `src/test/ui_test_stubs.cpp` 已由当前测试入口和本地 UI 测试结构替代。

代码扫描命中 wxj 功能链：QmClient 版本解析、网易云/DLL Hook、歌词模块、Axiom、Qm 配置域、Qm UI、Metal、EGL、地图渲染和客户端专有测试均在当前源码或 CMake 目标中存在。未发现 wxj 上游业务源码路径被无解释地遗漏。

## 官方 DDNet 代码扫描

已逐项检查协议、网络、snapshot、demo、输入、渲染调度、地图工具、EGL、macOS/iOS 和构建相关入口。当前源码中可直接定位到：

- `POWERUP_FREEZE`、`VERSION_DDNET_PICKUP_FREEZE`、协议回退和雪花资源；
- `m_pSnapshotDeltaSixup`、Rust `FinishIfNoDroppedItems`、snapshot delta 失败传播；
- 0.6/0.7 demo recorder 分流、暂停状态和 `GetAnimationPlaybackSpeed`；
- `NextUpdateTime`/`NextRenderTime` 调度合同与 Qm 等价适配；
- `backend_egl.cpp`、`FindEGL.cmake`、`map_render.cpp`；
- macOS `CFRunLoopRunInMode`、PCH/IPO、WavPack 外部依赖和 iOS display-cutout 处理；
- playermapping、旧客户端限制、重连、控制台 victim 槽位和输入前移。

当前对官方 `20.0` 源码树有 44 个路径级差异，不能直接视为漏合。已确认的差异类型包括：

- QmClient 自有 UI/Metal/EGL/歌词/配置扩展；
- DDNet 官方基础层拆分与 QmClient 现有基础层组织不同；
- 官方设置页拆分与 QmClient 设置架构不同；
- WavPack 外部子模块替代内置源码。

这些差异需要按符号和真实调用链判断，不能用文件名或提交 hash 自动合并。

## 已发现并合入的代码级缺口

扫描发现 Emscripten HTTP 是真实缺口：当前只有 `http_curl.cpp`，CMake 对 Emscripten 仍要求 Curl，也没有 Fetch API 后端。已合入官方 Fetch API 实现，新增 `src/engine/shared/http_emscripten.cpp/.h`，并同步：

- Emscripten CMake 不再查找或强制要求 Curl；
- `cmake/toolchains/Emscripten.toolchain` 启用 `FETCH=1`；
- Curl 后端在 Emscripten 下禁用，Fetch 后端接管 `IEngineHttp`；
- 编译库脚本同步跳过 Emscripten 的 Curl 依赖。

此前台账中标记为延期或待授权的冻结拾取、低刷新调度、独立 map renderer、PCH/IPO、WavPack、macOS resize、iOS cutout、console back、spin-wait 和 snapshot 32 位保护，扫描确认当前均已存在本地实现或等价调用链。

## 仍未完成的验证

代码存在不等于运行时完成。以下仍需平台或联机环境：macOS 真机窗口 resize/Metal、双客户端重连与换图、0.6/0.7 真实客户端、128 人映射、KCP/DSCP 链路、EGL 非 llvmpipe 驱动、iOS 触控和签名发布。

当前 `DDNET_VERSION_NUMBER`/`GAME_RELEASE_VERSION_INTERNAL` 为 `20000`/`20.0`，QmClient 自有 `QMCLIENT_VERSION` 保持 `3.0.2`。
