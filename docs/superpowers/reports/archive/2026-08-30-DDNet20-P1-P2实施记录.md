# DDNet 20.0 上游同步 P1/P2 实施记录

> 文档已归档：当前活动依据为 [DDNet 20.0 上游同步实施计划](../plans/2026-08-30-DDNet20上游同步实施计划.md)。

本记录对应 `ddnet-official/master` 的 `944ac7b28ef1` 基准，仅覆盖 P1 首批稳定性修复与 P2 iOS 依赖构建基础设施。代码和文档目前仍在工作树，尚未形成父仓库提交；逐提交处理结果见 `../plans/2026-08-30-DDNet20上游同步台账.tsv`。

## 已吸收的上游改动

- `bc2c2f930`：`map_convert_07` 持有替换图像的 `CImageInfo`，不再在局部 `ImgInfo` 释放后写入悬空 `m_pData`。
- `91eb6b94`：服务器快照 ID 池耗尽时，角色析构和 fallback snapshot 不再解引用空 ID；`CharacterHandlesEmptySnapshotIdPool` 覆盖构造与析构路径。
- `a38ba7bd`：tuning 浮点值缩放后若越过 `int` 范围或为 NaN，确定性降级为 `INT_MIN`；`Tunings.OutOfRangeBecomesIntMin` 覆盖正负超范围、NaN 与正常值。
- `0b108953`：移除 macOS/Xcode 不适用的 pkg-config 单目录 include hint。
- `a23094c69`：libpng 通过 pkg-config prefix 设置 `PNG_ROOT`，避免头文件与链接库跨安装前缀混用。
- `821d5ae4b`：带引号的 victim 参数现在与非引号参数一致校验，空 victim 被拒绝。
- `e58155fb8`：editor brush picker 依据持久 picker 状态复制扩展 tile 数据，避免松开空格后的崩溃。

`96d35b3f` 未合入：它已由上游 `76444d664` 撤回，最终方案为 `a23094c69`。

## iOS P2

- `scripts/compile_libs/` 支持 iPhoneOS arm64、iPhoneSimulator arm64 和 x86_64 三个 slice。
- 依赖静态库聚合为 `.xcframework`，并在产物中移除 slice 中间目录。
- curl 8.8.0 使用 Apple TLS 选项 `CURL_USE_SECTRANSP`；构建不依赖 BoringSSL。
- `docs/BUILDING-ios.md` 记录依赖生成前提与输出边界。
- 本机已验证 Xcode 26.6、iPhoneOS 26.5 SDK 和 iPhoneSimulator 26.5 SDK 可发现。
- 从空目录运行 iOS 依赖脚本成功生成 8 个 `.xcframework`。每个包含设备 `arm64` 和模拟器 `arm64`/`x86_64`；中间 slice 目录已清理。
- CMake 4.4 需要 FreeType/Ogg 显式采用 `CMAKE_POLICY_VERSION_MINIMUM=3.5`，脚本现与上游相同地传入该参数。SQLite 下载优先使用 macOS 自带 `curl`，并保留 `wget` 回退。

## iOS P3A/P3B 已实现，P3C 未完成

上游 `936f2b7c1`/`51a2ea409` 没有直接套用：网络、客户端和平台路径已经分叉，因此按当前 owner 适配了 SDL/OpenGL ES iOS target、app entry、资源打包、Rust target、Documents storage、前后台配置保存、Files URL export 和 EPIPE 后 socket 重建。恢复路径会关闭旧 socket，只有全部 client socket 成功重建后才加载 DDNet/STUN 信息并恢复主/分身连接；失败保留 offline，避免重复使用 broken socket。

上述 P3A/P3B 改动和文档仍在当前工作树，尚未提交。P3C 尚无 simulator runtime、AppIcon 编译、安装/启动、GLES、触控、联网、后台恢复、截图、Files export、退出、真机或 CI 证据；iOS 原生 Metal 不属于本批。
