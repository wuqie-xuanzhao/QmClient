# 设置页性能优化二次根因收口报告

日期：2026-06-14

## 范围

本轮按 `docs/superpowers/specs/2026-06-11-设置页性能优化总纲-重组版.html` 的口径继续收口，基线问题来自 `qm_perf_2026-06-14_03-33-41`：stable text coverage 仍被 `unplanned/key_mismatch/miss/stale/text_new` 阻断，`ingame_esc_open` 首帧出现百毫秒级卡顿，资源页只有 visible-first request，没有 visible-ready presentation。

## 代码收口

- stable text 生命周期：`InvalidateMenuTextPool()` 在 visible guard 内不再清空 planned descriptor/key 诊断集合，只标记 metadata dirty；新增 `EnsureSettingsMenuTextPlanReadyForVisible()`，visible guard 进入前只重建 plan metadata，不构建 text container。
- ingame ESC：新增 `PrebuildIngameEscTextPoolBeforeOpen(96)`，打开 ESC 前使用同一 text pool plan 做 bounded pump；`PrebuildSettingsTextPoolForLoading()` 在 `ingame_esc_open` 操作窗口下优先构建 ingame menubar/server info plan。
- settings key 共源：新增 `BuildSettingsShellTitleTextStyle()`，`settings-shell-title` 走 shared style helper；DDNet scrollbar/checkbox 代表项继续通过现有 stable wrapper 收集。
- 资源页 visible-ready：新增 assets visible preflight 结构与 telemetry；workshop thumb start 从卡片 draw loop 前移到 preflight/admission 阶段；draw 事件补充 `visible_ready/geometry_stable/thumb_starts_before_visible/thumb_starts_during_draw`。
- analyzer/report：新增 `assetsVisibleReadySummary`，report 区分 visible-first admission 与 visible-ready presentation；quality 对缺失 preflight、draw 中启动 thumb、geometry 不稳定继续给 warning。
