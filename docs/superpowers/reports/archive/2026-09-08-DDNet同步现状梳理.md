## 历史同步如何理解

1. 6 月至 7 月进行了选择性 cherry-pick、等价跳过及延期分类；归档交接中的 500 多条剩余上界已过时，不可直接重用。
2. 8 月完成基础库、客户端、编辑器等批量适配。[206 专项记录](../plans/2026-08-23-upstream-206-followup.md) 记录 128 人、HTTP 生命周期、多地图 tabs 的主体和后续修复。历史记录中的编译、全量测试、default gate 通过不代表当前 HEAD 已重新验证。
3. [8 月 30 日实施计划](../plans/2026-08-30-DDNet20上游同步实施计划.md) 使用 `20.0..1d507dad9081`，并在 9 月 1 日回填本地实现证据。协议、iOS、音频、数据库、网络和渲染均存在本地适配，不能仅用官方 hash 或标题判断遗漏。
4. 之后的 QmClient 上游音乐、歌词和 Windows 构建适配也已进入当前分支。

旧台账存在一个新发现的完整性缺口：计划写 235 条，TSV 实际只有 **234 条**，其中 155 条覆盖类记录、50 条本地合并/适配、19 条延期、10 条不适用。将末尾四个短 hash 解析为完整 hash 后，缺失的是 `bde42affe17af97d84fa21152c51e4d6a3951153`（ui.h popup 实现位置注释）。这是台账缺项，不直接表示功能缺失；旧台账未被本轮覆盖。合并 wrapper 和普通提交同时计数，也不能把这些数字当成独立功能数量。

19 条历史延期包括：10 条翻译/版本/CI/DSCP 策略、7 条 Emscripten 平台记录、2 条 payload 命名/协议批次记录。它们不是“已经全部合完”。

## 新增候选与已确认差距

`1d507dad9081..59968143f` 共 **89 个提交：49 个普通提交、40 个 merge wrapper**。加上旧范围，`20.0..59968143f` 共 324 个提交。这是可达性范围，部分作者日期早于旧基准日期，不能按日期过滤。

[新增提交台账](../plans/2026-09-08-DDNet新增提交台账.tsv) 保存全部 89 条及固定基准。49 个普通提交的 `git cherry` 均为 `+`，只说明没有精确 patch 等价，不说明全部缺失。

源码抽查确认两项尚未吸收：

- `54fcf119a`：`src/game/client/lineinput.cpp` 多行粘贴的后续行仍直接传给回调，缺少上游通过输入缓冲区限制长度的处理。属于 RCON 大文本崩溃候选。
- `350d0398c`：`src/engine/shared/demo.cpp` 仍在扫描前读取 timeline markers，缺少 marker 在首尾 tick 范围内的验证，录制侧也仍只检查 `Tick >= 0`。修复需保留本地 demo 裁剪行为。

上述结论来自真实 diff 与源码对照，尚未执行运行时复现或修复。

其他候选不能一概视为缺失：

- 音频无设备和样本状态已有 `14ef8c4c7` 本地适配，需与 `1a16a876b`、`ab5109826`、`b4eab43a1`、`bdd2253cb` 分别核对残余差异。
- 编辑器 popup 和保存后关闭已有本地地图实例生命周期处理，应对照 `ab17c9acd`、`f1edc1ae5`，不能机械搬迁官方状态字段。
- wavpack 5.9.0 依赖已进入子模块，但主项目 `cmake/FindWavPack.cmake` 仍保留 `src/engine/external/wavpack` fallback；子模块推送不代表主项目已完成 `837511294` 的构建与链接适配。

## 后续批次建议

1. 先检查并适配 JSON 校验/转义/栈溢出、RCON 粘贴、坏 demo、Android server 启动 use-after-free、skin 刷新与 OpenGL 退出崩溃。`17e3c2e83` 实际只改 teehistorian 测试和 UBSan suppression，不能仅凭标题把它当作 JSON 运行时修复。
2. 单列 wavpack 构建接线及各平台验证，连同 suppression 新增与回退提交整体核对。
3. 单列 snapshot 缓冲区与 32 位溢出、旧客户端组队/重连等兼容批次。保留当前 Rust snapshot 实现，不直接覆盖协议或布局。
4. 输入时序、低刷新率、精确唤醒和 macOS 窗口变动与本地 Metal/帧节奏改动交叉，单独审查；PCH、LTO、独立地图渲染器和新 UI 功能后置讨论。

已有实现但缺验收的历史项目：128 人与 0.6/0.7 混合会话、timeout reconnect、真实 HTTP 请求和退出、编辑器异步保存/关闭、iOS simulator/真机、相关 Linux Valgrind 集成。它们应与源码待合并候选分别追踪。
