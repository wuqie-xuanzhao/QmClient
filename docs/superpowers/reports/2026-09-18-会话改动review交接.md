### 2.1 跟随旁观 solo 玩家时，其他玩家**没有按预期淡化**（未解决，需实机定位）

现象：我（旁观）跟随处于 solo 区域的玩家 B 时，其他玩家 A 表现为正常透明度，像自由视角。作者强调其 `cl_show_others_alpha` **不是 100**，所以"alpha=100 看不出差别"的解释不成立。

已知代码事实：
- `CGameClient::IsOtherTeam` 的跟随分支已有 solo 扩展（`gameclient.cpp` 约 7482-7484）：`ClientId != SpectatorId && (m_aClients[SpectatorId].m_Solo || m_aClients[ClientId].m_Solo) → true`。
- tee alpha 唯一来源是 `players.cpp:831-839`（`OtherTeam → Alpha = cl_show_others_alpha/100`），其后没有覆盖回 1.0 的路径。
- 服务端 `CanSnapCharacter`（`src/game/server/entities/character.cpp:1206-1225`）对"被跟随的 B"不会丢（`CanCollide(B,B) == true`），对 A 只在 `m_ShowOthers == OFF` 时丢弃。
- 我加的硬隐藏（`IsSoloHidden`）**已回退**，不要按"完全隐藏"实现。

候选根因（均未实机证实，按可能性）：
1. 实机 `m_Snap.m_SpecInfo.m_Active` 为假或 `m_SpectatorId != B`（例如自由视角/Qm 的旁观 UI/multiview）→ 命中 freeview 分支直接 `false`；
2. `m_aClients[B].m_Solo` 陈旧（`m_Snap.m_aCharacters[B].m_HasExtendedData` 未刷新）；
3. 该区域其实是 `player_collision=0` 的 tune 区（只有 `m_CollisionDisabled`），不是 solo tile；
4. 参照玩家取错（渲染 A 时 `SpectatorId` 不是 B）。

**最小验证步骤**（加临时日志，一次性区分全部假设）：
- 在 `players.cpp:830`（`RenderPlayer` 入口）与 `gameclient.cpp` `IsOtherTeam` 入口各打一行：
  `LocalClientId / SpecInfo.m_Active / SpecInfo.m_SpectatorId / m_aCharacters[X].m_HasExtendedData / m_ExtendedData.m_Flags / m_aClients[B].m_Solo / m_aClients[B].m_CollisionDisabled / cl_show_others / cl_show_others_alpha / IsOtherTeam(A) 返回值`。
- 判读：`SpectatorId != B` → 根因 1；`SpectatorId == B` 且 `m_Solo == false` → 根因 2/3；`SpectatorId == B` 且 `m_Solo == true` 但 `IsOtherTeam(A) == false` → 逐条件复核 `IsOtherTeam`（边界：`TeamSuper`、`ClientId == SpectatorId`）。

约束：修复**只能落在客户端**（作者明确：不要改服务端；改了的回退）。
