## 性能工作

性能问题的**完整模型**见 **[性能优化总纲.md](性能优化总纲.md)**（本质 → 成因 → 测量 → 归因 → 优化 → 稳定性）；
对现有采集实现的**证据性审查**见 [性能采集体系审查.md](性能采集体系审查.md)。核心要点：

- 分两条独立战线：**帧时间分布**（CPU 单帧内工作串行堆叠 → low 帧）与**画质稳定性**（呈现/合成路径），手段不可互借。
- 优化的唯一目标是**把峰值摊平**，不是让快的更快。
- **采集体系不修，任何归因结论都不可信**：现有阈值门控使分布被截断、p99 不可信（详见审查文档）。
- 垂直同步是**用户可选**开关，有延迟增加的副作用，**不得强制开启**；稳定性下降的根因不在它。
- `docs/规格/性能优化路线图.html` 与 `待办整合规格.html` 已标注停用，仅作历史证据。
