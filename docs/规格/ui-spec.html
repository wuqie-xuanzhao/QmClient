QmClient UI 设计规格 2026

文档版本 v0.1 · 2026-09-24 · 分支 dyl_dev · 权威来源：docs/规格/界面规格.md

本文是面向开发者的 UI 规格参考。它描述 token 值、组件行为、布局规则和代码落点，不描述游戏逻辑。改动任何 UI 实现前，先核对本文对应章节。

设计原则

以下六条来自 docs/规格/界面规格.md §3，具有约束力：

  1. 一张卡片，一个真相源。 可见 rect、命中 rect、拖拽 rect、proxy、drop indicator 来自同一次最终布局。
  2. 单一视觉外壳。 禁止多层 glass、backdrop blur、白雾覆盖或页面私有 card wrapper。
  3. 先布局，后保底。 文本缩放和两行数值控件是兜底，不是常态布局工具。
  4. 交互优先于装饰。 拖拽、焦点、popup 反馈始终可用；装饰性运动可按用户配置减少。
  5. 公共接口优先于视觉相似。 两页看起来一样但改一处不能同步，仍视为未统一。
  6. 滚动与文本是热路径。 设计必须说明缓存、失效和预算。
必须清退的遗留路径：RenderQmSettingsGlassCard、TClientCacheSectionBoxRect、m_TClientSettingsCardDragState、页面私有 card padding / title offset / 缓存高度。迁移到对应页面时必须删除。

卡片网格 ← SettingsCardDeck.h · SettingsPageLayout.h

  • 双列阈值：TWO_COLUMN_MIN_WIDTH = 760px；窄屏自动单列。
  • 列间距 = 卡片间距 = CARD_GAP = 16px。
  • 拖拽可跨列；顺序持久化至 QmCardOrderModel，以最终视觉阅读顺序为准。
  • 卡片高度由最终内容测量结果产生，不允许使用上一帧缓存高度先绘一层 card 再用另一层内容覆盖。
  • 页面顶部子 Tab 始终占内容区全宽，不属于卡片网格，也不可拖拽。
卡片 stable ID 命名空间：qm:*（QmClient 卡片）、tclient:*（TClient 卡片）、deck:*（Deck 级卡片，如 overview/search）。来源：QmCardRegistry.cpp。

Header 规格

  • 标题：字号 HEADLINE = 14px，默认持续彩虹流动（qm_ui_card_rainbow_titles = 1）；关闭后使用 TEXT_PRIMARY 静态色，不改变 header 尺寸。
  • 副标题：字号 SMALL，仅 hover/focus 时显示，始终保留布局高度，不因显隐引起 reflow。
  • 拖拽热区：整个标题行（header rect）是拖拽热区；折叠箭头和子控件不启动拖拽。
  • 折叠箭头：右上角唯一折叠入口，折叠时旋转 -90°；卡片高度通过 spring CARD_REORDER 动画过渡。

卡片高度规则（核心约束）

高度双路径问题：目前渲染侧（HSplitTop 顺序消耗）与测量侧（加法公式）是两条独立代码路径，必须手工保持一致。这是已知架构债，详见 实施 → 卡片高度规范。

卡片高度由 SSettingsCardDefinition::m_Measure 回调给出，缓存于 deck 的 m_vContentHeights。失效条件有三：宽度变化、m_MeasureRevision 变化、m_MeasureEachFrame = true（被合同测试禁止在主要页面使用）。

Dropdown 下拉框 ← QmDropdown.h · QmDropdown.cpp

下拉面板 附加到 body 顶层，不受父级 overflow/stacking context 影响。位置计算以下拉框组件本身的位置为基准，不以视窗绝对坐标为准。

Dropdown 组件
OpenGL
Vulkan ✓
Metal

关键行为规格

  • Z-index：面板 z-index 必须覆盖所有 overlay，≥1000；parent 的 overflow:hidden 不能裁剪面板。
  • 位置计算：以 trigger 元素的 getBoundingClientRect 为基准，动态计算面板是否向上/向下展开（视窗边界检测）。
  • 滚动安全：页面滚动后 trigger 消失在视窗时，面板随之关闭而非错位浮动。
  • 动画：进入 ddIn（150ms, DECELERATE）：scaleY(.88) → 1, opacity 0 → 1；变换原点 top center。
  • 样式分层：外部边框（可选）→ 背景色 → 行分割线 → hover 高亮 → 当前选中。

按键识别组件 ← menus_settings_controls.h

状态示例
  • 点击进入监听：组件变为 listening 状态，显示脉冲动画，捕获下一个按键。
  • 右侧清空按钮：始终显示在 keybind 组件右侧，清除绑定返回 "未绑定" 状态。
  • ESC：取消监听，不修改绑定。
  • 监听状态：border-color: ACCENT，background: ACCENT_PRIMARY_DIM，脉冲 shadow 动画。

颜色选择器 ← UiForms.h

颜色选择器分两层：主界面（内置高级颜色色板，行内展示）和二级菜单（自定义颜色，弹窗形式）。

内置色板行（主界面）
  • 色板为固定高级内置色，点击即时应用；"自定义…" 触发二级菜单弹窗（全色轮 + Alpha）。
  • swatch hover：scale(1.12)，box-shadow: 0 2px 8px rgba(0,0,0,.4)，120ms DECELERATE。
  • 当前选中的 swatch 额外显示选中指示（white border 加粗 or checkmark）。

这是当前最重要的框架级约束。高度由两条独立代码路径决定（渲染侧 HSplitTop 消耗 vs 测量侧加法公式），必须手工保持同步，历史上已发生过 drift bug。
