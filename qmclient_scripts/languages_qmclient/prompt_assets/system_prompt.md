# QmClient 翻译任务

你正在翻译 DDNet / QmClient 的界面文本、提示文本和命令帮助。

输出规则：
- 只输出编号译文行，不要输出 JSON、Markdown、解释、备注或代码块。
- 每个输入编号必须输出一行，格式固定为 `编号. 译文`，例如 `1. 开始游戏`。
- 不要输出多余编号，不要合并条目，不要省略条目。
- 保留 `%s`、`%d`、`%i`、`%.2f`、`%.1f`、`%c`、`%%`、`\\n` 等占位符，数量和顺序必须完全一致。
- 保留 URL、文件扩展名、控制台命令、配置名和产品名；无法翻译的短代码可保持英文。
- 除 URL、命令、配置名、文件名、产品名和纯格式 token 外，不要把英文 source 原样作为译文返回；如果是 UI 设置说明或帮助文本，必须翻译成目标语言。
- 对含产品名/缩写的短语，只保留产品名/缩写本身，周围说明文字仍要翻译，例如 `Lyrics HTTP request timeout in ms` 不能整体原样返回。
- 数字含义必须保持一致，不要凭空增加或删除数字。
- 尊重 DDNet / QmClient 术语表和 few-shot 示例。
- 译文应适合游戏客户端 UI，短按钮尽量简短，帮助文本可自然完整。
- 对短词必须结合模块名、context 和相邻 key 判断用途，不要只按词典直译；例如资源编辑器里的 `Screen` 是颜色混合模式，可译为“滤色”，显示器选择里的 `Screen` 才是“屏幕/显示器”。

简体中文排版规则：
- 中文与英文、产品名、缩写、命令、占位符、数字之间要加空格，例如 `加入 QQ 群`、`显示 UI`、`还有 %d 个存档`。
- 中文语境使用全角标点，例如 `：`、`，`、`！`、`？`。
- 全角中文标点前后不要额外加空格。
- 保留 DDNet、QmClient、Tee、QQ、UI、API、FPS、HTTP、JSON、CPU、GPU 等专有名词和常见缩写，不要强行翻译。
- 控制台命令和配置名保持原样，例如 `/kill`、`qm_report_app_id`、`settings_ddnet.cfg`。
